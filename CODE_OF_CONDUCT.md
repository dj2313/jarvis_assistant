# Code of Conduct

## Pledge

We pledge to make participation in Friday Assistant a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, gender, experience level, nationality, or religion.

## Standards

**Welcome:** empathy, constructive feedback, focusing on what is best for the community.
**Unacceptable:** harassment, trolling, insults, publishing others' private info, or any conduct inappropriate in a professional setting.

## Enforcement

Report issues to the repository owner via GitHub. Maintainers may remove comments, commits, or contributors who violate this code.
